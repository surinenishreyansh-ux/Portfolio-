# SHREYASNH — Creative Developer Portfolio

A top-tier, dark-cinematic developer portfolio website built with React, Vite, Framer Motion, and Tailwind CSS.

## 🚀 Features
- **Dark Cinematic Aesthetic**: High-contrast typography, electric neon accents (`#00ff66`), glassmorphism, and subtle film noise texture.
- **Interactive Visuals**: Canvas 3D particle orb visualizer in Hero section.
- **Contextual Custom Cursor**: Magnetic follower with state changes (`VIEW`, `EXPLORE`, `→`).
- **Editorial Layouts**: Distinctive typography using `Syne` and `Plus Jakarta Sans`.
- **Project Showcase**: Detailed interactive cards with expandable detail modals for 6 core projects.
- **Skill Visualizer**: Categorized skill matrices and interactive technology clouds.
- **Responsive Navigation**: Glassmorphic header with full-screen animated mobile menu.
- **Zero Backend**: Deployable directly on Vercel or Render Static Sites out of the box.

## 💻 Tech Stack
- **Framework**: React 19 + Vite
- **Styling**: Tailwind CSS v4
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Effects**: Canvas Confetti & Custom HTML5 Canvas Particle Engine

## 🛠️ Local Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview build locally
npm run preview
```

## 📦 Deployment

### Vercel
- **Build Command**: `npm run build`
- **Output Directory**: `dist`

### Render Static Site
- **Build Command**: `npm install && npm run build`
- **Publish Directory**: `dist`
